# Meeting PDF font

`Pretendard-Regular.ttf` is the unmodified static Regular font distributed by
the installed AWS Content Plugin's bundled Pretendard assets. Its upstream is
`orioncactus/pretendard`; `LICENSE.txt` contains the upstream copyright and the
SIL Open Font License 1.1. The original reserved font name remains unchanged.

The renderer embeds only used glyphs and emits a Unicode text mapping. Unsupported
characters fail explicitly; a successful PDF must not silently drop text.
This license applies to the font, not to the user's generated document.
